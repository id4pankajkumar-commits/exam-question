Question 1 · Review

An engineer has working first-party Claude API code and must route the same calls through Amazon Bedrock using the current integration. What is true about the request body and event format across these surfaces?

  • A.The Messages body shape and SSE event format match; mainly the endpoint and model-ID prefix change.
  • B.Bedrock requires a completely different request schema with no messages array or content blocks.
  • C.Bedrock returns plain text rather than the JSON content blocks used by the first-party API.
  • D.The body is identical, but Bedrock disables streaming, so SSE events never appear.

Answer: A. The current Bedrock path keeps the Messages body and SSE format; the endpoint host and model-ID prefix differ.

Question 2

A compliance team must record every tool result to an immutable audit log without changing whether any tool runs. Which hook design best meets this need?

  • A.PreToolUse hook that blocks each tool until logging confirms success.
  • B.Stop hook that logs only the final response once per turn.
  • C.Memory-file rule asking the model to log its own individual tool results.
  • D.PostToolUse hook that writes each executed tool result to the audit log.

Answer: D. PostToolUse runs after each tool and cannot block execution, so it audits without changing tool behavior.
